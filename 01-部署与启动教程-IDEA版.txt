================================================================================
  校园二手教材流转与笔记共享系统
 
================================================================================

【文档说明】
  请按章节顺序操作。每完成一步可在心里打勾，避免跳步导致无法启动。
  本系统共三个可运行部分：
    1）后端服务（Java + Spring Boot）—— 必须最先启动
    2）管理后台 Web（Vue3 + Vite）—— 浏览器访问
    3）微信小程序（可选）—— 需微信开发者工具

  默认端口（勿与其他项目冲突）：
    后端：8088
    管理后台：5174
    MySQL：3306
    Redis：6379

================================================================================
  第一章  需要安装的软件清单与官方下载
================================================================================

  1.1 必装（缺一不可会导致项目跑不起来）
  ------------------------------------------------
  （1）JDK 17
      说明：本后端 pom.xml 指定 Java 17，请勿使用 JDK 8 或 JDK 11。
      推荐下载（任选其一）：
        • Eclipse Temurin 17（开源免费，推荐新手）
          https://adoptium.net/zh-CN/temurin/releases/?version=17
          选择 Windows x64，下载 .msi 安装包，一路下一步即可。
        • Oracle JDK 17（需账号）
          https://www.oracle.com/java/technologies/downloads/#java17-windows
      安装后验证：
        打开「命令提示符」或 PowerShell，输入：
          java -version
        应显示包含 "17" 的版本信息。

  （2）IntelliJ IDEA
      说明：用于打开后端与前端工程、内置 Maven，新手推荐 Ultimate 试用或 Community 免费版。
      下载：
        https://www.jetbrains.com/zh-cn/idea/download/?section=windows
      Community 版可免费开发本项目；安装时勾选：
        • Add "bin" folder to the PATH（可选，方便命令行）
        • .java 关联（可选）

  （3）MySQL 8.x 数据库
      说明：用于存储用户、教材、笔记等业务数据。
      下载：
        https://dev.mysql.com/downloads/mysql/
      选择 Windows (x86, 64-bit), ZIP Archive 或 Web Installer。
      安装时请牢记 root 密码；若设为 root/root，则与本项目默认配置一致，无需改代码。
      若密码不同：后面「修改配置文件」一节改 application.yml。

  （4）Redis
      说明：后端使用 Redis 做缓存；未启动 Redis 时，部分接口（如管理后台数据统计）可能报错。
      Windows 常用方式（任选其一）：
        • Redis 官方 Windows 移植（第三方维护）
          https://github.com/tporadowski/redis/releases
          下载 Redis-x64-*.zip，解压后双击 redis-server.exe 即可。
        • 或使用 WSL2 在 Linux 子系统内安装 Redis（略复杂，小白优先 zip 版）。
      验证：运行 redis-server 后，另开终端执行 redis-cli ping，返回 PONG 即正常。

  （5）Node.js（LTS 长期支持版）
      说明：用于安装管理后台前端依赖、运行 npm 命令。
      下载：
        https://nodejs.org/zh-cn
      选择 LTS（例如 20.x），安装后验证：
        node -v
        npm -v

  1.2 选装（微信小程序调试必装）
  ------------------------------------------------
  （6）微信开发者工具
      下载：
        https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
      安装后用自己的微信扫码登录；导入项目时选择「小程序」。

  （7）Maven（若 IDEA 已自带可跳过）
      IDEA 通常自带 Maven，可在 IDEA：
        File → Settings → Build, Execution, Deployment → Build Tools → Maven
      查看 Maven home path。若为空，可单独安装：
        https://maven.apache.org/download.cgi
      或使用 IDEA 自带的 Bundled (Maven 3)。

  （8）Git（用于拉取源码，若已是压缩包可跳过）
      https://git-scm.com/download/win

================================================================================
  第二章  解压源码与目录说明
================================================================================

  将「校园二手教材流转与笔记共享系统」源码解压到英文路径更佳，例如：
    D:\projects\campus-textbook-sharing\
  （避免中文路径少数环境下编码问题；若必须中文路径也可先试。）

  典型目录结构：
    ├── backend\              ← Java 后端（用 IDEA 打开此目录或上级均可）
    │   ├── pom.xml
    │   └── src\main\...
    ├── admin-web\            ← 管理后台 Vue 前端
    │   ├── package.json
    │   └── vite.config.js
    ├── miniprogram\          ← 微信小程序
    └── backend\src\main\resources\db\init.sql   ← 数据库初始化脚本

================================================================================
  第三章  初始化 MySQL 数据库
================================================================================

  3.1 启动 MySQL 服务
      Windows：服务里找到 MySQL80（名称可能略有不同）→ 启动。
      或使用 MySQL 自带的「MySQL Command Line Client」登录测试。

  3.2 导入初始化脚本（推荐）
      方法一：命令行（请把路径改成你的实际路径）
        mysql -u root -p < "backend\src\main\resources\db\init.sql"
      方法二：图形工具
        使用 Navicat、DBeaver、MySQL Workbench 等：
        1）连接到 localhost:3306，用户 root
        2）打开并执行 init.sql 全文
      脚本会创建数据库 textbook_db 及全部表和演示数据。

  3.3 核对数据库名
      本项目默认连接：
        jdbc:mysql://localhost:3306/textbook_db
      若导入成功，应能看到库 textbook_db。

================================================================================
  第四章  配置后端 application.yml（按需修改）
================================================================================

  文件路径：
    backend\src\main\resources\application.yml

  必须核对项：
    spring.datasource.url        → 数据库地址与库名 textbook_db
    spring.datasource.username   → 一般为 root
    spring.datasource.password   → 你的 MySQL root 密码（默认示例为 root）
    spring.redis.host            → 本机填 localhost
    spring.redis.port            → 6379

  server.port 默认为 8088，若无端口占用请勿随意修改（前端已按 8088 对接）。

================================================================================
  第五章  使用 IntelliJ IDEA 启动后端
================================================================================

  5.1 打开工程
      File → Open → 选择 backend 文件夹（或包含 backend 的整个项目根目录）。

  5.2 等待 Maven 依赖下载
      右下角若提示「Import Maven Project」，点 Enable Auto-Import。
      首次需联网下载 jar，时间较长属正常现象。

  5.3 确认 JDK
      File → Project Structure → Project → SDK 选择 17。

  5.4 启动 Redis
      务必先启动 redis-server.exe（或你的 Redis 服务），保持窗口不关。

  5.5 运行主类
      找到：
        backend\src\main\java\com\textbook\TextbookApplication.java
      右键 → Run 'TextbookApplication'
      控制台出现 Spring Boot 启动成功、无红色 Error，且最后一行类似：
        Started TextbookApplication in xx seconds
      说明后端已在 http://localhost:8088 提供服务。

  5.6 常见启动失败
      • 端口被占用：关闭占用 8088 的其他程序，或改 application.yml 的 server.port（同时改前端 baseURL）。
      • 连不上 MySQL：检查服务是否启动、账号密码、库 textbook_db 是否存在。
      • 连不上 Redis：先启动 Redis；或排查防火墙。

================================================================================
  第六章  使用 IDEA 或命令行启动管理后台（admin-web）
================================================================================

  6.1 安装依赖（只需第一次或 package.json 变更后）
      打开终端，进入 admin-web 目录：
        cd admin-web
        npm install
      若 npm 很慢，可使用国内镜像（可选）：
        npm config set registry https://registry.npmmirror.com

  6.2 确认接口地址
      打开文件：
        admin-web\src\api\request.js
      其中 baseURL 应为：
        http://localhost:8088
      （若后端改了端口，此处同步修改。）

  6.3 启动开发服务器
      在 admin-web 目录执行：
        npm run dev
      控制台会提示 Local 地址，本项目 vite.config.js 固定端口为 5174，一般为：
        http://localhost:5174/

  6.4 用 IDEA 集成 npm（可选）
      在 IDEA 中打开 admin-web 文件夹：
      右键 package.json → Show npm Scripts → 双击 dev

  6.5 浏览器访问
      打开 http://localhost:5174/login
      使用《测试账密说明.txt》中的管理员账号登录。

================================================================================
  第七章  微信小程序（miniprogram）调试说明
================================================================================

  7.1 前提
      后端必须先启动（8088）。
      手机真机调试时，不能把 baseUrl 写成 localhost（手机访问不到电脑）。
      需把小程序里请求的域名改成你电脑的局域网 IP，例如：
        http://192.168.1.100:8088
      修改位置通常为 miniprogram 下的 app.js 或 utils 里的 baseUrl。

  7.2 微信开发者工具
      导入项目 → 选择 miniprogram 目录 → 填写测试 AppID（可使用测试号）。
      详情 → 本地设置 → 勾选「不校验合法域名」（仅开发环境）。

  7.3 正式发布
      需在微信公众平台配置服务器域名 HTTPS，并部署正式后端；此处略。

  第八章  推荐启动顺序小结（给客户照着做）
================================================================================

  ① 启动 MySQL 服务
  ② 启动 Redis（redis-server）
  ③ IDEA 运行 TextbookApplication（后端 8088）

================================================================================
  第九章  生产环境打包简述（进阶）
================================================================================

  后端打包：
    在 backend 目录执行：mvn clean package -DskipTests
    生成 jar 后：java -jar target\xxx.jar
  管理后台打包：
    admin-web 目录：npm run build
    将 dist 目录部署到 Nginx 等静态服务器，并配置反向代理到后端。
