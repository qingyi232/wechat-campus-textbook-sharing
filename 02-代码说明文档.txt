  校园二手教材流转与笔记共享系统 — 代码与架构说明

【一、项目总体架构】

  本系统采用前后端分离 + 微信小程序：

    ┌─────────────────┐     HTTP/JSON      ┌──────────────────────────┐
    │  admin-web      │ ◄──────────────►  │  backend (Spring Boot)    │
    │  Vue3 + Vite    │    JWT 鉴权        │  REST API + MyBatis-Plus │
    └─────────────────┘                    └───────────┬──────────────┘
                                                       │
    ┌─────────────────┐                               │ JDBC
    │  miniprogram    │ ◄─────────────────────────────┤
    │  微信小程序      │     同上 API + Token           │
    └─────────────────┘                               │
                                                       ▼
                                            ┌──────────────────┐
                                            │ MySQL (textbook_db) │
                                            └──────────────────┘
                                            ┌──────────────────┐
                                            │ Redis (缓存)      │
                                            └──────────────────┘

  默认端口：
    后端：8088（application.yml：server.port）
    管理后台开发服务器：5174（admin-web/vite.config.js）

【二、目录与模块说明】
================================================================================

  2.1 backend（Java 后端）

    技术栈摘要：
      • Spring Boot 2.7.x
      • JDK 17
      • Spring Security + JWT 无状态会话
      • MyBatis-Plus
      • Druid 数据源
      • Redis + Spring Cache（部分统计/缓存）
      • 本地文件上传目录：配置项指向 ./uploads/（相对运行目录）

    入口类：
      com.textbook.TextbookApplication
      注解：@SpringBootApplication、@MapperScan("com.textbook.mapper")、
            @EnableCaching、@EnableScheduling

    典型包结构（按 com.textbook 下实际为准）：
      config\          安全配置、JWT 过滤器、Redis、跨域等
      controller\      REST 控制器，路径多为 /api/...
      service\         业务逻辑
      mapper\          MyBatis Mapper 接口
      entity\ / dto\   实体与传输对象
      common\          统一响应、异常、常量等

    安全配置要点（SecurityConfig）：
      • /api/auth/**、/api/common/**、/uploads/** 匿名可访问
      • 其余 /api/** 需登录（JWT）

    数据库脚本：
      backend\src\main\resources\db\init.sql
      含建库、建表、演示数据（用户、教材、笔记等）。

  2.2 admin-web（管理后台）

    技术栈：
      Vue 3、Vite、Element Plus、axios

    关键文件：
      package.json       依赖与脚本（npm run dev / build）
      vite.config.js     开发服务器端口 5174
      src\api\request.js axios 封装，baseURL 指向后端（默认 http://localhost:8088）
      src\router         路由与菜单
      src\views          各业务页面（用户、教材、笔记、借阅规则等）

    运行方式：
      开发：npm install 后 npm run dev
      生产：npm run build 产出 dist，由 Nginx 等托管

  2.3 miniprogram（微信小程序）

    典型结构：
      app.js / app.json    全局配置、页面列表
      pages\               各功能页面
      utils\               请求封装、工具函数（若有）

    开发注意：
      • 开发阶段在微信开发者工具中关闭域名校验
      • 真机调试需使用局域网 IP + 同网段，不能使用 localhost

【三、接口与鉴权流程（概念）】
================================================================================

  3.1 登录
      管理端通过 /api/auth 相关接口提交用户名密码，成功后返回 JWT。
      后续请求在 Header 中携带 Authorization: Bearer <token>。

  3.2 静态资源与上传
      /uploads/** 允许匿名访问（便于图片预览）；具体权限以业务为准。

【五、扩展与二次开发建议】
================================================================================

  • 新增业务表：修改 init.sql 或单独 migration，同步 Entity/Mapper/Service/Controller。
  • 新增管理端菜单：admin-web 路由 + 视图 + API 模块。
  • 小程序新页面：pages 注册 + 调用后端已有或新接口。
  • 上线前务必更换 JWT 密钥、数据库密码，并启用 HTTPS 与正式域名。
